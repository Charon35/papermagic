# PaperMagic

3D-розмальовки: сайт, матеріали для Instagram і рекламні креативи.

- `papermagic-site/` — сайт (Netlify публікує саме цю папку)
- `instagram/` — шаблони постів/рілсів (`src/studio.html`), скрипти рендеру, план і тексти
- `brand/` — логотип у SVG
- `ads/` — скрипти для рекламних креативів (сирі відео зберігаються окремо, не в Git)
- `archive/` — файли, які зараз не використовуються на сайті
