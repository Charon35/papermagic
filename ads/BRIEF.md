# Бриф: 4 рекламні відео-креативи для Meta (Instagram / Facebook)

## Задача
З 7 вертикальних відео з iPhone (діти малюють і склеюють розмальовки PaperMagic) змонтувати **4 різні креативи** для реклами в Meta. Монтаж, тексти, музика — на розсуд автора: обрізати, прискорювати, домальовувати графіку.

## Вихідні відео
Google Drive (відкрита папка): https://drive.google.com/drive/folders/1SZvANvB42Mjrn47m1j3AVHYXIw4dUnFc
Файли: `IMG_4390 (1).MOV`, `IMG_4391 (1).MOV`, `IMG_4392 (1).MOV`, `IMG_4393 (1).MOV`, `IMG_4396 (1).MOV`, `IMG_4397 (1).MOV`, `IMG_4398 (1).MOV` (~220 МБ разом).
Скачувати в `ads/raw/` (папка в `.gitignore`, у Git сирі відео не кладемо), напр. через `pip install gdown && gdown --folder <url> -O ads/raw`.

## Формат результату
- `ads/out/ad-1.mp4 … ad-4.mp4`: **9:16, 1080×1920**, H.264 + AAC, 15–30 с, перші 2 с мають зачепити (hook).
- Для кожного: обкладинка `ad-N-cover.jpg` і текст оголошення в `ads/AD-TEXTS.md` (основний текст, заголовок, опис, CTA-кнопка Meta).
- Текстові плашки — з запасом від країв (безпечні зони Reels: ~250 px зверху й ~350 px знизу), великий жирний шрифт, читається без звуку.
- **Музика тільки власна або з відкритою ліцензією** (згенерувати самому, наприклад синтезом у Python/ffmpeg). Ніяких треків із чужими правами: Meta блокує рекламу з неліцензованою музикою.
- Обличчя дітей, якщо трапляться в кадрі, краще обрізати або не використовувати.

## Ідеї для 4 креативів (можна змінювати)
1. **Процес → результат:** швидкий монтаж «аркуш → розмальовування → вирізання → готова фігурка», фінал з ціною й CTA.
2. **Проблема → рішення для батьків:** «Чим зайняти дитину без телефону?» → дитина захоплено малює → «30–60 хв творчості за 99 ₴».
3. **Набір / вигода:** усі 8 фігурок за 449 ₴, акцент на подарунку й на тому, що PDF можна друкувати скільки завгодно.
4. **Емоція / UGC:** найживіші моменти дитини з фігуркою, мінімум тексту, «Зроблено своїми руками».
