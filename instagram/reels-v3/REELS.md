# Навчальні рілси v3 для @papermagic_ua

Три спокійні рілси для батьків про те, що дає дитині малювання. Стиль новий, не такий, як у рекламі та рілсах v2. Це «паперовий зошит»: заголовки шрифтом із засічками (Lora), рукописні примітки (Caveat), кремові картки зі «скотчем», природні кольори (шавлія, теракота), мʼякі переходи й теплий кольоровий грейд.

| Файл | Тривалість | Звук | Обкладинка |
|---|---|---|---|
| `reel-1.mp4` «Чому дитині важливо малювати?» | 18 с | власна lo-fi музика | `reel-1-cover.jpg` |
| `reel-2.mp4` «Як одна розмальовка тренує руки» | 17 с | власна lo-fi музика | `reel-2-cover.jpg` |
| `reel-3.mp4` «Година з екраном vs година з розмальовкою» | 19 с | власна lo-fi музика | `reel-3-cover.jpg` |

**Музика:** новий трек, раніше ніде не використаний: спокійний lo-fi (електропіано, мʼякий бас, «щіточки», калімба, легкий шум платівки, 74–82 BPM). Він синтезований кодом у `src/music.py`, тому прав третіх осіб немає. Трек з Instagram не додавайте, бо він накладеться на цей.

**3D-фігурки:** поліцейське авто й хіпі-фургон зібрані зі справжніх шаблонів (`papermagic-site/img/sheet-3.jpg`, `sheet-1.jpg`). Лінії з листа «розфарбовані олівцем», а модель склеєна так само, як папір у житті: дві боковини й стрічка-дах по профілю. Фігурки відрендерені на столі з ваших відео (`src/fig/`).

Формат: 9:16, 1080×1920, 30 к/с, H.264 + AAC. Тексти не заходять у безпечні зони Reels (≈250 px зверху й ≈350 px знизу).

## Рілс 2 — «Як одна розмальовка тренує руки дитини» (`reel-2.mp4`)

**Сценарій:** хук «Як одна розмальовка тренує руки дитини · 3 етапи 👇» → Етап 1 «Розмалювати» (сила натиску, точність) → Етап 2 «Вирізати» (координація обох рук, контроль руху) → Етап 3 «Скласти й склеїти» (дрібні рухи пальців, терпіння) → «Підказка за віком»: 3–4 роки розмальовує, мама допомагає; 5–6 років вирізає разом з дорослим; 7+ років збирає фігурку сам. На фоні обертається 3D-фургон.

**Підпис:**
```
Одна розмальовка — три тренування для рук ✋
1️⃣ Розмалювати: дитина вчиться контролювати натиск і не виходити за лінії
2️⃣ Вирізати: працюють обидві руки разом — це координація
3️⃣ Скласти й склеїти: найдрібніші рухи пальців і терпіння до результату

Підказка за віком:

🧒 5–6 років — вирізає разом з дорослим
👦 7+ — збирає фігурку сам

Збережіть собі 📌 · 3D-розмальовки PaperMagic — посилання в профілі 👆
```

## Рілс 3 — «Година з екраном vs година з розмальовкою» (`reel-3.mp4`)

**Сценарій:** екран поділено навпіл. Угорі ілюстрація: дитина зі спини перед телевізором, що мерехтить, з підписами «дивиться… → гортає далі… → вже втомився». Внизу справжнє відео: «створює ✨ → вирізає ✂️ → збирає сам 🙌». Далі результат: угорі «0 іграшок», внизу «2 нові іграшки» (3D-машинка й фургон на столі). Фінал: «Обирайте годину, після якої щось залишиться».

```
✏️ Година з розмальовкою: розмалював, вирізав, склеїв — і має нову іграшку, зроблену своїми руками
```

## Як перезібрати

Потрібні сирі відео в `ads/raw/` (див. `ads/BRIEF.md`), ffmpeg, Python з `numpy`, `scipy`, `opencv-python-headless` і Playwright.

```bash
instagram/reels-v3/src/fig/make_figs.sh            # 3D-фігурки з шаблонів → instagram/reels-v3/build/fig
python3 -I instagram/reels-v3/src/build.py 1 2 3   # рілси й обкладинки → instagram/reels-v3/
PREVIEW=1.5,8,14 python3 -I instagram/reels-v3/src/build.py 1   # лише ключові кадри → build/r1/preview.jpg
```

- `src/edit.json`: сегменти (кліп, початок, тривалість, швидкість, кадрування, `zoom`, `scene` — 3D-сцена, `place` — пів екрана).
- `src/reels.html`: оверлей (картки, рукописні примітки, ілюстрація «екран», фінальні картки).
- `src/music.py`: lo-fi музика (3 варіації, по одній на рілс).
- `src/fig/`: шаблон → маска деталі (`net.py`) → «олівцеве» розфарбування (`colorize.py`, кольори в `seeds.json`) → профіль моделі (`model.py`) → 3D-рендер у браузері (`fig3d.html`, three.js 0.169, `render3d.js`).
- Шрифти Lora, Caveat, Manrope мають ліцензію SIL OFL (файли ліцензій у `src/fonts/`).
