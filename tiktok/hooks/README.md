# TikTok-хуки PaperMagic (`@papermagic.ua`)

Три короткі ролики, зроблені саме під TikTok. Хук видно вже в кадрі 0.0 с: готова кольорова фігурка в русі й великий текст до 6 слів. Далі щось змінюється кожні 1–2 с (поп, поворот 3D-фігурки, перемотка, спалах), а в кінці йде логотип PaperMagic і «3D-розмальовки · друкуй вдома».

Формат: 1080×1920, 30 к/с, H.264; звук AAC 192 кбіт/с, 48 кГц, стерео. Тексти лежать у безпечній зоні TikTok (x 60–900, y 200–1500), тож їх не перекривають кнопки праворуч і підпис знизу. Це перевіряє `src/check.js`: він проходить кожні 0,1 с ролика.

**У TikTok лишайте «Оригінальний звук».** Музику написано й синтезовано кодом спеціально для цих роликів (`src/sound.py`), без чужих семплів і мелодій, тож прав третіх осіб на неї немає. Не додавайте трек з бібліотеки TikTok поверх, бо він заглушить акценти, поставлені під кадри. Якщо все ж хочете інший трек, беріть `hook-N.mp4` без звуку.

## Хук 1 — «Це був аркуш паперу 👀» (`hook-1.mp4`)

**Сценарій:** готова 3D-поліцейська машинка вже крутиться на жовтому тлі, «серйозно 👇» → «⏪ перемотуємо…»: машинка крутиться назад і знебарвлюється → спалах і чорно-білий аркуш «Ось він 📄 просто PDF», камера наїжджає на деталь → «Розфарбуй ✏️»: олівець проходить по боковині й лишає колір, «Виріж ✂️ і склей 🧴», лічильник хвилин творчості → знову 3D-машинка з конфеті «А тепер — іграшка 🚓» → логотип.

**Підпис:**
```
Спершу це був звичайний аркуш паперу 📄 Роздрукуй, розфарбуй, виріж, склей — і в дитини нова іграшка 🚓
```
**Хештеги:** `#3dрозмальовка #паперовіфігурки #творчістьздітьми #щозробитиздитиною #papermagic_ua`

## Хук 2 — «Вгадай, хто з них був папером?» (`hook-2.mp4`)

**Сценарій:** троє кубо-героїв уже стоять у кадрі, ще двоє вискакують на 0.3 і 0.6 с → «Пиши номер у коментарях 👇»: прожектор по черзі на кожному героєві з плашкою «№1 ?…№5 ?» → «Відповідь… 🥁», усі тремтять → «УСІ 😄»: кожен герой перевертається й показує свій аркуш-шаблон, конфеті, «усі 5 — з паперу ✂️» → логотип і вся команда.

**Підпис:**
```
Чесно, ви вгадали? 😄 Пишіть номер у коментарях 👇 Усі 5 супергероїв — з паперу, дитина збирає їх сама ✂️
```
**Хештеги:** `#супергерої #паперовіфігурки #розмальовки #заняттядлядітей #papermagic_ua`

## Хук 3 — «POV: дитина 40 хв без телефону» (`hook-3.mp4`)

**Сценарій:** готовий 3D-фургон уже крутиться, «як це було 👇» → етапи з таймером, що росте від 0 до 40 хв: «1. Розфарбовує ✏️» (контур заповнюється кольором) → «2. Вирізає ✂️» (ножиці йдуть по контуру, аркуш падає, деталь піднімається) → «3. Склеює 🧴» (боковини й дах з'їжджаються, спалах, 3D-фургон) → «Готово! 🙌 40 хв без екрана» з конфеті → логотип.

**Підпис:**
```
40 хвилин тиші, зосередження і жодного мультика 🙌 Розфарбувати, вирізати, склеїти — і фургон готовий 🚐
```
**Хештеги:** `#дитинабезгаджетів #творчістьздітьми #3dрозмальовка #заняттядлядітей #papermagic_ua`

## Звук

Три окремі інструментальні треки, кожен рівно на тривалість свого ролика. Звук іде з 0.0 с, без тиші на початку. Гучність -14 LUFS integrated, піки не вище -3 dBTP (ліміт -1 dBTP), наприкінці fade-out 0.3 с. Інструменти синтезовано кодом: укулеле (щипкова струна Karplus-Strong), ксилофон, глокеншпіль, піаніно, мʼякий бас, легкі клапи й шейкер, плюс SFX із фільтрованого шуму. Клубних бітів немає.

**Хук 1, «Це був аркуш паперу».** Бадьоре укулеле-піцикато в ре мажорі з ксилофоном: 114 BPM до перемотки, далі 120 BPM.
- 0.0 с: яскравий акорд укулеле й дзвіночок разом із першим кадром; 1.15 с: поп на «серйозно 👇».
- 2.1–2.9 с «⏪ перемотуємо…»: музика звучить задом наперед із прискоренням і «плаванням» стрічки, далі «вжух» у спалах.
- 2.9 с, аркуш «просто PDF»: дзвіночок і шелест паперу, грув тихішає. 4.6 с: поп на «Розфарбуй ✏️», 4.75–5.9 с шурхіт олівця. 5.9 с: два клацання ножиць і розгін клапами.
- 6.4 с, 3D-машинка з конфеті: яскравий акорд ре мажор (укулеле + піаніно), дзвіночок, блискучий «шурх». 7.4 с: поп на «з одного аркуша ✨».
- 8.4 с, логотип: акорд і дзвіночок; 9.9 с: фінальний акорд.

**Хук 2, «Вгадай, хто з них був папером?».** «Підкрадливий» ксилофон навшпиньки в ля мінорі (восьма = 0.35 с, тож 2.1 / 5.6 / 6.3 / 8.4 с лягають на сітку), щипковий бас.
- Pop на кожного героя: 0.0 с (троє вже в кадрі), 0.3 і 0.6 с (вискакують ще двоє).
- 2.1, 2.8, 3.5, 4.2, 4.9 с, прожектор №1…№5: поп і нотка дзвіночка, що щоразу вища.
- 5.6–6.3 с «Відповідь… 🥁»: музика стихає, барабанний дріб з крещендо.
- 6.3 с «УСІ 😄»: тріумфальний акорд ля мажор (мінор перемикається на мажор), клап, «шурх» конфеті. 6.55–7.03 с: п'ять висхідних ноток на перевороти героїв, 6.9 с поп на плашку. Далі весела частина в мажорі.
- 8.4 с, логотип: акорд і дзвіночок, 8.5–8.78 с п'ять попів героїв; 9.8 с: фінальний акорд.

**Хук 3, «POV: 40 хв без телефону».** Спокійніше піаніно з укулеле-арпеджіо у фа мажорі, 100 BPM на 3/4: один такт = 1.8 с = один етап, тож зміни етапів (1.8 / 3.6 / 5.4 / 7.2 с) припадають на «раз».
- 0.0 с: дзвіночок і акорд; 0.9 с: поп на «як це було 👇»; на 1.8, 3.6, 5.4 с поп на плашку етапу.
- 2.0–3.5 с «1. Розфарбовує ✏️»: шурхіт олівця.
- 3.75–4.67 с «2. Вирізає ✂️»: клацання ножиць кожні 0.22 с; 4.8 с шелест аркуша, що падає.
- 5.45 с «3. Склеює 🧴»: мʼякий «вжух» деталей, 5.75 с «пшик» клею, 6.4 с «пуф» склеювання на спалах і дзвіночок на 3D-фургон.
- 7.2 с «Готово! 🙌»: яскравий акорд, два дзвіночки, «шурх» конфеті. 8.6 с, логотип: дзвіночок; 9.6 с: фінальний акорд піаніно.

**Файли:** `audio/hook-N.wav` (48 кГц, 16 біт, стерео) і `hook-N-sound.mp4`. Відео в `hook-N-sound.mp4` скопійовано без перекодування (`-c:v copy`). Перевірено: 2 потоки (H.264 + AAC), тривалість аудіо дорівнює тривалості відео, кліпінгу немає, акценти звірено з кадрами.

Перезібрати лише звук:
```bash
python3 -I tiktok/hooks/src/sound.py tiktok/hooks/audio/hook-1.wav 1 10.4
```

## Як перезібрати

Рендер важкий, тому запускайте його в хмарі, а не на ноутбуці. Потрібні Node + Playwright (Chromium), Python 3 з `opencv-python-headless`, `numpy`, `scipy` і ffmpeg.

```bash
bash tiktok/hooks/src/build.sh        # усі три ролики; або: build.sh 2
```

- `src/hook-{1,2,3}.html` — сцени. Кадр за часом можна відкрити як `hook-N.html?t=СЕКУНДИ` через локальний сервер з кореня репозиторію (`python3 -m http.server`, далі `/tiktok/hooks/src/hook-1.html?t=3`).
- `src/common.js`, `src/style.css` — таймінг, підписи в стилі TikTok, 3D-оберти, фінальна картка.
- `src/build.sh` — збирає все: 3D-моделі машинок з аркушів (`instagram/reels-v3/src/fig/make_figs.sh`), потім `src/prep.py` (деталі «контур / розфарбовано»), повні оберти фігурок, `src/render.js` (кадри через Playwright) і ffmpeg.
- `src/sound.py` — музика й SFX (крок 4 у `build.sh`: WAV і зведення з відео).
- `src/check.js` — перевіряє безпечну зону для текстів; `src/sheet.py` — контактний аркуш кадрів для перегляду.
- Проміжні файли лежать у `tiktok/hooks/build/` (у `.gitignore`).
