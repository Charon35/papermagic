## Поліцейська машинка

`police-process.mp4` — 23.7 с, 1080×1920, 30 к/с, H.264 (High, yuv420p), **без аудіодоріжки** (звук додаєте самі в застосунку TikTok).
У кадрі тільки аркуш поліцейської машинки та його шлях до іграшки. Жодних написів, стікерів, логотипів чи фінальної картки немає. Тло — м'який бузковий колір з ледь помітною текстурою паперу.

## Послідовність

| Час | Етап | Ключовий кадр |
|---|---|---|
| 0–2.2 с | Чистий чорно-білий аркуш, камера повільно наїжджає | `police-process-1.png` |
| 2.3–8.2 с | Олівець розфарбовує ліву боковину, стрічку-дах, праву боковину; колір з'являється штрихами «змійкою» | `police-process-2.png` |
| 8.4–13.1 с | Ножиці проходять по контуру кожної деталі, вирізана деталь піднімається з тінню | `police-process-3.png` |
| 13.2–14.3 с | Аркуш з дірками відʼїжджає вниз, деталі лягають на стіл і повертаються | — |
| 14.3–18.2 с | 3D: боковини стають вертикально, стрічка згинається по профілю й склеюється, зверху сідає мигалка | `police-process-4.png` |
| 18.2–23.7 с | Готова 3D-машинка повільно обертається | `police-process-5.png` |

Друкований логотип, блок «Інструкція…» з ножицями й клеєм, а також слово на середній панелі стрічки прибрано з аркуша **лише для цього відео** (`src/clean.py`), щоб у кадрі не було тексту. Напис POLICE — частина малюнка машинки, тому він лишився.

## «Блискавка 95»

Та сама послідовність і таймінг. Боковини червоні з жовтими «95» і блискавкою, вікна блакитні, шини темні. На стрічці жовті задні фари, «95» на даху, очі на лобовому склі, кремовий Rust-eze на капоті й рот спереду. Олівець червоний. Боковини на аркуші надруковані з нахилом ≈7°. Для 3D їх вирівняно по лінії низу коліс (`src/racer/fig.py`), а в пласкій позі вони лежать точно як на аркуші, тож перехід 2D → 3D непомітний.

## «Блискавка 95» з реальних відео (`blyskavka-95-real.mp4`)

Живі кадри з `ads/raw/` (відео з Google Drive, посилання в `ads/BRIEF.md`). Обличчя дітей у кадр не потрапляють:

| Час | Що | Джерело |
|---|---|---|
| 0–5.0 с | рука розфарбовує аркуш червоним олівцем | `IMG_4393.MOV` 0.3–5.8 с, ×1.1 |
| 5.0–8.3 с | ще кольори (жовтий, синій) | `IMG_4396.MOV` 1.6–5.9 с, ×1.2 |
| 8.3–13.2 с | вирізання ножицями | `IMG_4397.MOV` 0.2–6.9 с, ×1.3 |
| 12.9–13.9 с | склеювання: машинку тримають у руках | `IMG_4398.MOV` 0–0.65 с, сповільнено ×0.5 (далі в кадр заходить інша фігурка) |
| 13.9–19.9 с | готова машинка обертається на тому самому столі | 3D (`src/real/colors.json` — кольори як у дітей) |

Переходи м'які (0.3 с), тексту поверх і звуку немає. **Але на справжньому аркуші надруковані «PaperMagic» та «Інструкція…», і в живих кадрах їх видно** (на стрічці й на звороті аркуша). Це друк самого продукту, з відео його не прибрати.
Порожнього аркуша й готової «Блискавки» у відео немає, тому готова машинка в кінці — 3D. Блискавку розфарбовували доросла й дитина, тож і в кадрі їхні руки.

Перезібрати (спершу `bash tiktok/process/src/build.sh racer`, сирі відео — в `ads/raw/`):

```bash
bash tiktok/process/src/real/build.sh
```

## Як перезібрати (тільки в хмарі)

```bash
bash tiktok/process/src/build.sh police
bash tiktok/process/src/build.sh racer
```

Потрібні node + playwright (Chromium), python3 + `opencv-python-headless` + `numpy`, ffmpeg і `pdfimages` (poppler-utils) для PDF-аркуша. Кожна збірка триває ≈9 хв. Проміжні файли лежать у `tiktok/process/build/<фігурка>/` (не в git).

- `src/figs.json` — налаштування фігурок: аркуш, що прибрати, деталі, кольори олівця, ім'я файлу;
- `src/racer/` — «Блискавка 95»: `netx.py` (деталі з аркуша високої роздільності), `colors.json` (розфарбовка), `fig.py` (вирівнювання й 3D-модель), `fig.sh`;

- `src/clean.py` — чистий аркуш з `papermagic-site/img/sheet-3.jpg`;
- `src/figs.sh` — деталі й 3D-модель поліцейської машинки (конвеєр `instagram/reels-v3/src/fig/`: `net.py`, `colorize.py`, `model.py`, `police.extra.json`);
- `src/prep.py` — аркуш ×3, розфарбовані деталі, карта порядку розфарбовування, контури для ножиць;
- `src/timeline.js` — спільний таймлайн (тривалість етапів, камера 3D);
- `src/process.js` — 2D-сцена (аркуш, олівець, ножиці). `police-process.html` і `blyskavka-95-process.html` лише підключають її з налаштуваннями фігурки; у браузері можна відкрити `?t=СЕКУНДИ`;
- `src/fold3d.html` + `src/render3d.js` — 3D-складання й обертання (three.js), кадри з прозорим тлом;
- кадри сцени рендерить `tiktok/hooks/src/render.js`, кодує ffmpeg з `-an`.

Щоб змінити темп, правте `src/timeline.js` і запускайте `build.sh` знову (він спільний для обох роликів).
